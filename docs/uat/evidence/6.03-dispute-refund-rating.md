Roll-up run 2026-09-26. Testnet only. The sub-stories 6.03a–g each tested one
slice of this card. This page judges the card's own eight criteria (SD-01..SD-08
in `test-plan.md`) from their results and from a re-check against today's code.

## 1 · Live preconditions, re-checked 2026-09-26

Against `https://orizon-agents-be-stellar.onrender.com`:

- `/readiness`: ready. The signer and the ledger's scorer are the same account
  (`ratings.writer=scorer`), so a dispute rating could be written.
- `/openapi.json` has all six dispute routes but no security scheme. So the
  deploy still runs a build older than backend `08efeda`, which adds one.
- `POST /api/disputes/{id}/uphold` still answers `503 dispute_refunds_disabled`
  (D-051).
- The live 6.03 specs (`dispute-path`, `dispute-eligibility`, `durability`,
  `reputation-consequence`, `adjudication-door`) all pass on `chromium-desktop`,
  30 of 30, their expected failures included. `DP-01` still fails as expected:
  no run has a settlement to dispute (D-050, behind D-039). The contracts repo
  has had no commit since 2026-09-24.

So on the deploy no step can be disputed and nothing can be upheld. No
criterion that needs money to move can be proven there today.

## 5 · Recommendation

**No-go** for signing off 6.03. One criterion is blocked on the deploy, four
fail in code, and Deliverable 3 is not captured.

Before `DISPUTE_REFUNDS_ENABLED` goes on, in this order:

1. The deploy runs backend `08efeda` or later. `/openapi.json` shows a
   security scheme once it does. This carries the D-053 and D-056 fixes.
2. `MAX_REFUND_USDC` on Render is unset or a finite positive number (D-054).
3. `DATABASE_URL` is still set (DU-05 checks it on every run).

Then the one live session: a settled run (needs D-039/D-050), refunds on with
`API_KEY` set (D-051), an uphold through the API rather than the script
(D-066), capturing the dispute tx, the refund tx and a recording. The
checklist is `checklists/6.03f-phone-and-screen-reader.md`. That session turns
SD-01 green and proves SD-02 on-chain. SD-03, SD-06, SD-07 and SD-08 need the
fixes for D-060, D-054, D-066 and D-075.
