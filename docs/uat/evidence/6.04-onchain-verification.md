# Story 6.04 — independent verification of every on-chain claim

Story 6.04 is the last gate before the completion report goes to the Ambassador
Chapter Lead. Its question is narrow: can every claim the sprint makes be checked
by someone who does not trust the team? A transaction that resolves but shows
something other than its claim counts as a failure, and a worse one than a dead link.

## What was verified, and against what

| claim set | where it is published | independent source |
| --- | --- | --- |
| explorer links | `https://orizons.xyz/evidence` (FE `content/evidence/index.json`, snapshot as of 2026-09-30) | Horizon testnet, Stellar RPC |
| §6.3 success metrics | the same index, and BE `scripts/sow_metrics` | chain data counted by UAT's own tool |
| workflow attestations | the same index, and the Week-4 submission | `AttestationRegistry.get`; a re-seal simulated on RPC |
| external operators | the same index, and BE `app/data/team_wallets.json` | Horizon account history and funding trails |
| public artifacts | `/app/register`, `/guide/list-your-agent`, `/demo` | a fresh browser context, with no wallet and no session |
| §6.2 checklist links | the index's PR, repository, document and page links | GitHub pages, raw files, and the live endpoints |
| a fresh workflow | UAT's own testnet buyer, run on 2026-10-02 | Horizon, at the moment of the run |

The asset is native testnet XLM throughout. No mainnet transaction was signed.
