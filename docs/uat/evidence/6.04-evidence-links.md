# 6.04 evidence — every explorer link in the evidence index (OV-01)

Run 2026-10-02, on testnet. OV-01: every explorer link in the public evidence
index resolves on testnet and shows the contract, function, addresses and
amounts the index claims.

## 1 · Method

- **The links.** Read from the live page `https://orizons.xyz/evidence`, not
  from a copy: 59 distinct `stellar.expert/explorer/testnet` links (48
  transactions, 5 contracts, 6 accounts), all on testnet. The page's source,
  `content/evidence/index.json` in the frontend repo, carries the same 59
  links (82 occurrences); live and source do not differ.
- **The claims.** Each link's label in the index, pinned as exact values in
  `tools/onchain-verify/facts.ts`.
- **The chain.** Only Horizon testnet (`/transactions`, `/operations`,
  `/accounts`) and Stellar RPC testnet (`getLedgerEntries`,
  `getTransaction`). Contract-call arguments are decoded from the operation's
  XDR by `tools/onchain-verify/scval.ts`, with no SDK and nothing from the
  app's own API.
- **The test.** `tests/evidence-index.spec.ts` checks every link on each run:
  a link added to or dropped from the live page fails the first test until
  its claim is pinned. A transaction must be successful, on the claimed UTC
  day, signed by the claimed key, one call to the claimed contract and
  function with the claimed arguments, and move exactly the claimed native
  XLM and no other asset.

Match: **yes** when the link shows everything the label claims; **partial**
when the call, addresses and amounts match but the label also states
something the chain does not show; **no** when the chain shows something
else; **dead** when the link does not resolve.
