curl targets `localhost:8787` (the port the agent listens on), sends
`Idempotency-Key` equal to `dispatch_id`, and computes `ts` from `date +%s`. The
agent answered `200`.

```
https://your-agent.onrender.com/ -> 401 {"error": "signature does not verify — if this is every request, check that ORIZON_ENDPOINT_URL is byte-identical to the URL you bound"}
```

— is refused by an agent configured the way `.env.example` shows.
