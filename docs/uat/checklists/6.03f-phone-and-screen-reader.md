# 6.03f checklist — the dispute receipt on the deploy, a real phone and a screen reader

The browser drill (`tools/dispute-ui-drill/`, evidence `6.03f-dispute-ui.md`)
read every state on a local stack with real testnet transactions. What it cannot
do is below. Paste each result back so it can be filed in the evidence doc.

## Before you start: the deploy must be able to hold a dispute

All three must be true, or none of this can run on orizons.xyz:

1. A paid run records a settlement (D-050): `GET /api/tasks/<task>/disputes`
   shows a non-null `settlement`.
2. The fix for the private money-path defect D-053 is deployed.
3. Only then, `DISPUTE_REFUNDS_ENABLED=true` on Render (D-051), with Dan
   holding the operator key.
