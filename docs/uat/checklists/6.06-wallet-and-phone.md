# 6.06 checklist — wallets and a real phone

The parts of story 6.06 that automation cannot reach: a real wallet extension
opening a real prompt, a person pressing **Reject**, and a real phone. Everything
else in 6.06 is checked by `tests/operator-surfaces.spec.ts`.

Work through it in order and fill in every **Record** field as you go. Paste the
results table at the end back when you are done. Copy expected text *exactly*
as quoted: a difference is a finding, even a small one.

## Rules

- **Testnet only.** Every wallet on Testnet before you open orizons.xyz; fund
  each new account with friendbot, never with real funds.
- **Do not clean up.** Leave every registration and binding in place; they are
  evidence.
- **One new agent per wallet.** Use `uat606_<wallet>_1` (for example
  `uat606_freighter_1`), and `_2` if you need another. Never reuse an id from an
  earlier run.
- **Do not work around a failure.** If a wallet cannot do a step, record what it
  showed and move to the next wallet. A wallet that cannot sign a message is a
  finding, not a blocker.
- **Record what you see, not what you expected.** Screenshots are named
  `6.06-<wallet>-<step>.png`.
