# Evidence index

Artifacts this suite captures as SOW deliverables. Every row names the image,
the criterion it serves, the exact input behind it, the state of the system at
capture, and — the part an image cannot carry — **how that state was
produced**. A screenshot whose origin is not recorded is decoration, not
evidence.

Each artifact is regenerated by the test named in its row; the images and notes
in this directory are written by those tests, not by hand.
